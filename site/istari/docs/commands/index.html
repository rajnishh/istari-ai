    #All commands

    Every command the CLI knows about. Category matches what ist --all-commands shows: Primary shows in ist --help, Power user works but is hidden, Deprecated still runs and redirects, Coming soon only prints a notice, and Internal commands are called by hooks and daemons rather than people, so they are left out here.

    #Command flags

    These commands validate their flags and print the same list with --help. Every flag they accept:

    #ist approve

    FlagMeaning
    --anywaySkip the plan-staleness check and approve as-is
    --lldForce the LLD design stage ON before implementation
    --no-lldForce the LLD design stage OFF (default: planner recommendation)
    --help / -hShow this help message

    #ist board

    FlagMeaning
    --type <type>Filter JIRA by type (story/bug/task/epic)
    --priority <level>Filter JIRA by priority (critical/high/medium/low)
    --status <status>Filter JIRA by status (e.g. "To Do", "In Progress")
    --sprint <sprint>Filter JIRA by sprint (default: current)
    --limit <N>Max JIRA tickets to return (default: 50)
    --include-doneInclude Done/Closed/Resolved/Cancelled tickets
    --include-subtasksInclude Sub-task tickets
    --allShortcut for --include-done --include-subtasks
    --browserUse Chrome browser scraping instead of API (JIRA only)
    --no-jiraSkip JIRA fetch
    --no-prs-to-reviewSkip PR-review-requested fetch
    --no-my-prsSkip my-open-PRs fetch
    --only <source>Show one section only: jira / reviews / my-prs
    --plainPlain-text output - no colours, no OSC 8 hyperlinks. Useful for piping to grep / wc / less without -R.
    --help / -hShow this help message

    #ist clean

    FlagMeaning
    --dry-run / -nShow what would be cleaned without writing
    --prune-missing-cwdAlso remove completed/failed rows whose workDir no longer exists on disk
    --help / -hShow this help

    #ist graph

    FlagMeaning
    --html [path]Self-contained page, no network. Default: a temp file
    --dot [path]Graphviz DOT. stdout when no path is given
    --openOpen the --html page in the default viewer
    --in <tier>project / shared / global / all
    --project <key>One named project. Implies --in project unless --in is also given
    --kind <KIND>DECIDED / OPEN / PARKED / LEARNED
    --since <window>30d / 4w / 6m / 1y / YYYY-MM-DD
    --liveLive claims only. Off by default: a lineage graph without superseded claims has every arrow target removed
    --limit <n>Claim cap (default 500)
    --help / -hShow this help message

    #ist kill

    FlagMeaning
    --allKill all running agents
    --role <role>Which agent role to kill when several match one ticket (dev/qa/tl/sa/devops/security)
    --help / -hShow this help message

    #ist logs

    FlagMeaning
    --tail <N>Show last N lines only
    --follow / -fFollow log output in real-time (like tail -f)
    --rawForce the raw session log for v2 pipeline jobs (skip the event feed)
    --help / -hShow this help message

    #ist pick

    FlagMeaning
    --role <role> / -rAgent role (dev/qa/tl/sa/devops/security, default: dev)
    --model <model> / -mModel override (e.g. sonnet, opus)
    --gate <plan|none|pre-push>Pause the pipeline after a stage for 'ist approve'. Comma-combine (plan,pre-push); default from config.pipeline.plan_gate.
    --restartDiscard saved plan/gate state and start the job over
    --dry-runShow what would happen without spawning
    --hereWork in the current directory (skip worktree creation)
    --base <branch>Base the diff/scope/PR on a branch other than main (stacked tickets)
    --at <when>Schedule the pick instead of spawning now: "21:30"/"9am" (next occurrence), "in 2h"/"in 45m", or "reset" (when the engine limit lifts)
    --help / -hShow this help message
    --trust <level>Trust level (interactive/supervised/autonomous/silent) (advanced)
    --budget <tokens> / -bToken budget for the agent (advanced)
    --budget-usd <amount>USD budget for the agent (advanced)
    --no-budgetDisable budget kill-switch (advanced)
    --no-predictionSkip cost prediction (advanced)
    --engine <engine> / -eEngine to use (claude/codex/ollama) (advanced)
    --lldForce the LLD design stage ON (advanced)
    --no-lldForce the LLD design stage OFF (default: auto) (advanced)
    --legacyUse the v1 one-shot pipeline (opt out of v2 supervised) (advanced)
    --follow / -iStream the pipeline event log until the gate or a terminal state (advanced)
    --supervisedWatch for rate-limit / quota exhaustion + auto-failover (advanced)
    --no-supervisedForce supervisor off (default for interactive runs) (advanced)
    --dry-prBlock destructive gh PR commands; agent runs end-to-end but nothing posts. Logs would-be commands to <workDir>/.istari-dry-pr/log.txt (advanced)
    --draftDraft-PR review gate: deliver a draft PR, halt for your review, then verify-then-decide on your concerns. Reply via 'ist answer <ticket> ready/<concerns>'. (advanced)
    --unattendedRun to PR creation with no human turn. Base drift auto-rebases (conflict -> draft PR, never a force-push), exhausted verification ships a draft PR with the failures in the body, and the draft-review dialogue is skipped. Safety stops (scope, secrets, infra, AI-%) still park. (advanced)
    --mockUse placeholder ticket if real sources unreachable (default: fail loudly) (advanced)
    --browserUse browser scraping for the JIRA ticket (advanced)
    --no-graphifySkip the graphify graph check (no graph-status.md written) (advanced)
    --quiet / -qMinimal output (advanced)
    --porcelainAlso print a machine-readable IST_PICK_RESULT line (spawned vs attached) for scripts such as 'ist assemble' (advanced)

    #ist plan

    FlagMeaning
    --open <N>Show archived plan.N.md (rejected/replanned versions)
    --pathPrint the file path only (for piping/scripting)
    --editor <editor>Editor to open with (used with --open; defaults to ist open detection)
    --help / -hShow this help message

    #ist resume

    FlagMeaning
    --engine <engine>Engine to resume on (claude-code/codex/ollama). If omitted, resumes on the original engine.
    --model <model>Model override (e.g. sonnet, opus, or an Ollama model)
    --budget <tokens>Add additional token budget
    --after <delay> / -bgRun as background agent (default: interactive)
    --foreground-timerKeep this terminal attached, wait for --after/--at, then resume interactively
    --help / -hShow this help message

    #ist start

    FlagMeaning
    --role <role> / -rAgent role (dev/qa/tl/sa/devops/security, default: dev)
    --model <model> / -mOverride model (opus/sonnet/haiku)
    --engine <engine> / -eEngine to use (claude/codex/ollama, default: claude)
    --scratchCreate an exploratory worktree off the current branch (optional [name]). No ticket required; auto-names if name omitted. Sets up the workspace and exits - no agent spawn.
    --tempMark session as temporary (auto-cleaned on completion)
    --hereWork in the current directory (skip worktree creation)
    --mirrorMirror the session to Discord
    --no-graphifySkip graphify graph check (no graph-status.md written)
    --verbose / -vPrint the underlying claude/codex command line
    --quiet / -qMinimal output
    --help / -hShow this help message

    #ist status

    FlagMeaning
    --all / -aShow sessions from all projects (not just current directory)
    --help / -hShow this help message

    #ist uninstall

    FlagMeaning
    --yesActually remove - without this nothing is written
    --dry-run / -nShow the plan and exit (this is the default)
    --purgeAlso remove your data, after exporting it first
    --export-to <dir>Where --purge writes the export (default ~/.istari-export/<timestamp>)
    --no-exportSkip the export --purge would write
    --keep-binaryLeave the ist binary in place
    --help / -hShow this help

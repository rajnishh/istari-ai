    Workflow catalog

    Everything the WHEN/THEN builder (ist workflow create and the dashboard form) can combine.

    #WHEN - triggers

    IdTrigger
    pr-assigned-to-meNew PR assigned to me for review
    i-open-a-prI open a PR
    my-pr-reviewed-with-changesSomeone reviews my PR with changes requested
    my-pr-approvedMy PR gets approved
    pr-merged-to-mainPR merged to main
    new-pr-in-repoNew PR opened in repo
    ci-failsCI pipeline fails
    ci-fails-on-mainCI pipeline fails on main
    build-passes-after-mergeBuild passes after merge
    bug-assigned-to-meBug assigned to me
    ticket-assigned-to-meTicket assigned to me
    high-priority-ticketHigh priority ticket created
    every-morningEvery morning at 9 AM
    every-hourEvery hour
    every-fridayEvery Friday at 5 PM

    #THEN - actions

    IdAction
    review-automaticallyReview it automatically
    self-review-before-teamSelf-review before team
    fix-the-codeFix the code based on feedback
    merge-itMerge it
    fix-automaticallyFix it automatically
    run-testsRun tests
    investigate-failureInvestigate the failure
    track-build-statusTrack build status
    generate-standupGenerate daily standup
    generate-reportGenerate a report
    notify-onlyJust notify me
    security-scanRun security scan
    block-deployBlock deploy if P1 bugs open
    verify-bug-fixVerify the bug fix
    check-test-coverageCheck test coverage
    transition-jira-ticketMove JIRA ticket
    generate-sprint-summaryGenerate sprint summary
    monitor-blocked-ticketsAlert on blocked tickets
    dependency-auditRun dependency audit
    assign-and-notifyAssign and notify team

    #ALSO - extra steps

    IdExtra step
    notify-discordNotify me on Discord
    move-jira-ticketMove JIRA ticket to status
    assign-to-personAssign to person
    add-labelAdd a label to PR
    comment-on-prComment on PR
    request-reviewRequest review from team
    run-shell-commandRun a shell command
    send-webhookSend HTTP webhook

    Role presets (a starter set of workflows per role): Technical, Non-technical.

    #Step types (YAML workflows)

    Step typeWhat it does
    spawn-agentStart an agent from a template (for example code-reviewer)
    shellRun a shell command
    githubCall GitHub through gh
    jiraCall JIRA
    discordPost to Discord
    httpSend an HTTP request
    conditionBranch on an expression
    parallelRun child steps at the same time
    review-lifecycleCheck, record or re-review a PR in the review lifecycle
    wait-confirmationHuman approval gate
    chainTrigger another workflow
    for-eachLoop over an array
    comment-reply-checkDetect PR-owner replies to review comments

    v4 event-action handlers: github.approve, github.close, github.comment, github.label, github.merge, github.request-changes, http, jira.assign, jira.comment, jira.transition, log, notify, notify.discord, notify.email, notify.slack, review-pr, set-var, shell, spawn-agent, stop, triage-bug.

    v4 event sources: pollers, cron schedules, internal hook events (for example session.started, review.complete) and CLI-emitted custom events.

    #Shipped workflow templates

    TemplateSetDescription
    auto-mergev2Merge approved PRs when all checks pass
    bug-patrolv2Detect bugs assigned to me and auto-dispatch agents
    bug-trackerv2Track bugs assigned to me - notify, optionally auto-fix
    ci-monitorv2Watch CI pipelines for failures on main branch
    feedback-fixerv2Address review feedback on my PRs - auto-fix code and push
    post-mergev2Track CI stages after merge - notify per stage; on pass, optionally move the ticket to the verification column (default "In Test", never Done).
    pr-reviewerv2Review PRs assigned to me - code + security review, inline comments
    self-reviewv2Self-review my PRs before requesting team review
    task-completev2On PR merge, move the linked JIRA ticket to the team verification column (default "In Test"). Never auto-Done, never reassigns the reporter.
    task-reviewv2Auto-move JIRA ticket to "In Review" when PR is created
    task-startv2Auto-move JIRA ticket to "In Progress" when agent starts working
    bug-patrolv4Detect bugs assigned to me and auto-dispatch dev agents
    bug-triagev4Auto-triage bugs - verify against recent work, comment, reassign or queue
    ci-fixv4Auto-investigate CI failures on main branch
    ci-monitorv4Watch CI pipelines for failures on main branch
    daily-standupv4Generate and post daily standup at 8am on weekdays
    morning-catchupv4Generate morning catch-up summary at 8:30am on weekdays
    qa-testv4Automated API testing when ticket moves to QA
    qa-discoverQADiscover API endpoints from PR diff + OpenAPI spec
    qa-executeQAExecute API tests against a running server
    qa-generateQAGenerate test payloads from endpoint schemas
    qa-postQAPost test results to JIRA and Discord
    qa-reportQAGenerate test report from execution results
    qa-wait-reviewQAWait for QA to review generated payloads before execution
